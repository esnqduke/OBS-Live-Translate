# Управление субтитрами и mute

В свойствах фильтра Live Translate доступны общие настройки для всех стилей:

| Настройка | Диапазон | По умолчанию |
| --- | --- | --- |
| Минимальное время чтения строки | 100–60000 мс | 3000 мс |
| Время на символ | 0–500 мс | 60 мс |
| Минимальный интервал между строками | 0–30000 мс | 1500 мс |
| Максимум видимых строк | 1–3 | 3 |
| Скорость анимации | 10–500% | 100% |
| Размер текста | 0 (авто) или 12–200 пкс | авто |
| Выравнивание | по стилю/источнику, слева, по центру, справа | по стилю |
| Анимация появления и прокрутки | вкл./выкл. | вкл. |
| Промежуточные результаты | вкл./выкл. | вкл. |

Время чтения начинается после полного появления строки. При включённом времени на символ используется большее из минимального времени и 1000 мс + число символов × время на символ. Интервал строк рассчитывается аналогично; непрочитанная строка защищена от вытеснения. Для фиксированной длительности и фиксированного интервала установите время на символ в 0.

При слишком маленькой области вывода число строк уменьшается. Browser подбирает автоматический размер текста под доступную область; ручной размер сохраняется, а число строк уменьшается. Если даже одна строка не помещается, увеличьте область или уменьшите шрифт; GDI+ использует параметры текстового источника и ручной размер из фильтра. Browser поддерживает все семь эффектов, GDI+ — свои существующие эффекты. Настройки фона относятся к Browser.

Изменение параметров показа сохраняет модель и непрочитанный текст. Кнопка «Очистить субтитры и накопленное аудио» намеренно отменяет текущую фразу и очищает очередь. Кнопка сброса восстанавливает только новые параметры показа, сохраняя выбранные модель, стиль и фон.

## Микрофон заглушён в OBS

Mute родительского аудиоисточника в микшере OBS, включая горячие клавиши, автоматически останавливает передачу аудио в STT, отменяет незавершённое распознавание и очищает показанные и ожидающие субтитры. Поздние результаты отменённой фразы отбрасываются. После unmute распознаётся только новая речь; модель Whisper остаётся загруженной.

Проверяется состояние mute именно того источника, на котором установлен фильтр. Регулятор громкости 0% и отключение микрофона аппаратной кнопкой не являются состоянием mute OBS. Сам фильтр не меняет аудиопоток.

При установке версии с этими настройками обновляйте DLL и папку data вместе при закрытом OBS. Обновите кеш страницы Browser после обновления файлов.
