# Stable release — 2026-11-04

The accepted browser-caption baseline for OBS Live Translate. This release label does not change the DLL's embedded version.

- Local Russian transcription and Russian → English translation through Whisper.
- Up to three caption rows, with reading priority and at least three seconds fully readable after entrance.
- Restored Matrix, Console and Cyberpunk effects.
- Matrix code rain, Fantasy and Grand Cathay-inspired themes with independent backgrounds.
- CPU or Vulkan inference and a built-in loopback bridge; no separate model server.

For 1920×1080 scenes, start with a Browser Source at **1920×384** and Local file disabled. See [Windows setup](../INSTALL-WINDOWS.md).

## Compatibility

Windows x64, AVX2/FMA/F16C CPU, current Microsoft Visual C++ v14 x64 runtime. Tested on OBS 32.2.2 and NVIDIA RTX 4070 SUPER 12 GB. The prebuilt Vulkan DLL requires system `vulkan-1.dll` even in CPU mode. Only the selected Vulkan0 device is supported; other hardware/OBS releases require validation. Models are downloaded separately.

## Validation

Four native suites, journal/HTTP tests, real-libobs protocol tests, 20 JavaScript tests, Chrome animation/lifecycle captures and a real native bridge ACK check. The visual result was accepted in OBS on the tested workstation. No universal hardware/performance guarantee is implied.

Future changes should preserve the accepted reading behavior and keep this release available for rollback. Close OBS before restoring a complete plugin folder from a prior release. Models and scene backups are separate.
