# OBS Live Translate — установка и настройка на Windows

Инструкция для стабильной версии **stable-2026-11-04**. Подходит для переноса на другой совместимый Windows-ПК без исходников и среды разработки.

Плагин распознаёт русскую речь или переводит её на английский локально, затем показывает субтитры в OBS. **Модель запускается внутри плагина автоматически: отдельный сервер поднимать не нужно.**

## 1. Что потребуется

| Компонент | Требование |
|---|---|
| Windows | Windows 10/11, 64-разрядная x64-система |
| Процессор | x64 с AVX2, FMA и F16C; для очень старых CPU нужна другая сборка |
| OBS Studio | 64-разрядная версия с источником «Браузер»; плагин проверялся в OBS **32.2.2** |
| Библиотеки Microsoft | Актуальный Microsoft Visual C++ **v14 Redistributable x64**, совместимый с MSVC 2026 |
| Vulkan Runtime | Стабильный GPU-пакет требует доступную системную `vulkan-1.dll` даже при обработке на CPU; обычно её устанавливает совместимый драйвер видеокарты |
| Видеокарта | GPU-ускорение необязательно; для него нужны совместимая видеокарта и её драйвер с Vulkan |
| Модель | Один из трёх точных файлов из раздела 4 |
| Интернет | Для первоначальной загрузки OBS, библиотек, драйвера и модели; во время распознавания не требуется |

Это не универсальный бинарник для любого оборудования: 32-разрядные Windows, ARM64 OBS и CPU без перечисленных инструкций этой сборкой не проверены и не поддерживаются как целевая конфигурация. На слабом CPU перевод может отставать от речи.

**Если на ПК нет Vulkan Runtime, эта стабильная GPU-DLL не загрузится даже с выключенным GPU.** Простое переключение галочки не устраняет зависимость DLL. Для такого ПК нужна отдельная актуальная CPU-сборка без Vulkan; в зафиксированном стабильном пакете её нет. Старый CPU-архив не содержит нынешнее браузерное оформление. Не подменяйте runtime скачанной с постороннего сайта DLL.

Официальные загрузки:

- [OBS Studio](https://obsproject.com/download). Новые версии OBS могут отличаться от проверенной; [предыдущие выпуски](https://github.com/obsproject/obs-studio/releases/tag/32.2.2) позволяют воспроизвести проверенный вариант.
- [Microsoft Visual C++ v14 Redistributable — описание](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist/), [установщик x64](https://aka.ms/vc14/vc_redist.x64.exe). Установите пакет не старее использованных инструментов сборки; одного старого пакета Visual C++ 2015 может быть недостаточно.

**Не нужны:** Python, Node.js, Visual Studio, CMake, CUDA Toolkit, Vulkan SDK, whisper-server, Docker, API-ключи и облачный аккаунт. Vulkan для работы GPU предоставляет установленный драйвер видеокарты. Не копируйте случайные `vulkan-1.dll` или системные DLL OBS в папку плагина.

## 2. Что перенести с исходного ПК

Откройте [стабильный релиз на GitHub](https://github.com/esnqduke/OBS-Live-Translate/releases/tag/stable-2026-11-04) и скачайте:

```text
OBS-Live-Translate-stable-2026-11-04-windows-x64.zip
caption-styles-sha256.json
SHA256SUMS.json
README-INSTALL-WINDOWS-RU.md
```

Сам README доступен в репозитории. Также перенесите выбранный файл модели со старого ПК или скачайте его по ссылкам ниже. **Модели не входят в ZIP.** Архив исходников нужен только для разработки. В стабильном Vulkan-пакете предусмотрен режим CPU, но системная `vulkan-1.dll` всё равно требуется. Не используйте архивы других версий вместо актуального браузерного пакета.

Поместите файлы в удобную папку, например `C:\OBS-Live-Translate-Setup`. Не требуется сохранять прежний диск `G:` или имя пользователя. Настройки звуковых устройств и путь модели на новом ПК выбираются заново.

Если переносите настройки OBS, предварительно экспортируйте нужную коллекцию сцен и профиль средствами OBS. Их перенос необязателен: можно создать новые источники вручную по этой инструкции. Обновление плагина не переносит сцену автоматически.

## 3. Установка плагина

1. Установите OBS Studio и Visual C++ Redistributable x64. Если Windows попросит перезагрузку, выполните её.
2. Полностью закройте OBS.
3. Распакуйте `OBS-Live-Translate-stable-2026-11-04-windows-x64.zip`.
4. Если плагин уже установлен, сохраните его папку в отдельное место. Сохраните также нужные коллекции сцен через OBS перед обновлением.
5. Скопируйте **всю папку `obs-live-translate` из архива** в:

   ```text
   C:\ProgramData\obs-studio\plugins\
   ```

   Итоговая структура должна быть такой:

   ```text
   C:\ProgramData\obs-studio\plugins\obs-live-translate\
   ├── bin\64bit\obs-live-translate.dll
   └── data\
       ├── locale\en-US.ini
       ├── locale\ru-RU.ini
       ├── licenses\...
       └── overlay\
           ├── index.html
           ├── overlay.css
           ├── overlay.js
           └── model.mjs
   ```

   `ProgramData` обычно скрыта: вставьте путь в адресную строку Проводника. Если Windows запросит права администратора на копирование, разрешите их для этой операции. Не создавайте вложенность `obs-live-translate\obs-live-translate`.

6. Не оставляйте вторую старую DLL плагина в другой папке загрузки OBS. При обнаружении дубликата сначала сохраните его резервную копию, затем оставьте одну актуальную установку.
7. Запустите OBS. На аудиоисточнике в списке добавления фильтров должен появиться **«Live Translate — локальный Whisper (RU / EN)»**.

Это рекомендуемый путь для обычной установки OBS, в том числе когда само приложение установлено на другом диске. Для **portable OBS** используйте его каталог `data\plugins\obs-live-translate\` с той же внутренней структурой; путь зависит от используемой portable-сборки. См. [официальное руководство по установке плагинов](https://obsproject.com/kb/plugins-guide).

### Проверка целостности

`caption-styles-sha256.json` содержит контрольные суммы каждого файла плагина. Чтобы проверить установленную обычную версию, откройте PowerShell в папке с этим JSON и выполните:

```powershell
$ErrorActionPreference = 'Stop'
$pluginPath = Join-Path $env:PROGRAMDATA 'obs-studio/plugins/obs-live-translate'
$manifest = Get-Content -LiteralPath '.\caption-styles-sha256.json' -Raw | ConvertFrom-Json
foreach ($entry in $manifest) {
    $file = Join-Path $pluginPath $entry.path
    if ((Get-FileHash -LiteralPath $file -Algorithm SHA256).Hash -ne $entry.sha256) {
        throw "Не совпала контрольная сумма: $($entry.path)"
    }
}
Write-Host 'Все файлы плагина совпадают с манифестом.'
```

Для portable-установки замените значение `$pluginPath` на её фактическую папку плагина.

Для публичного релиза используйте ручное копирование папки по инструкции выше. Локальные вспомогательные установщики разработчика не входят в публичный комплект; скачивать исходники для установки не требуется.

## 4. Выбор и загрузка модели

Начните с **medium-q5_0**, если есть подходящий GPU. Для CPU или первого запуска на неизвестном ПК начните с **base**. **large-v3** поддерживается, но требует больше ресурсов и на нашем контрольном переводе не дала преимущества перед medium-q5_0.

| Файл | Точный размер, байт | Когда использовать |
|---|---:|---|
| `ggml-base.bin` | 147951465 | Первый запуск, CPU, меньшая нагрузка |
| `ggml-medium-q5_0.bin` | 539212467 | Основной проверенный вариант для GPU |
| `ggml-large-v3.bin` | 3095033483 | Необязательное сравнение на более мощной системе |

Официальные ссылки на закреплённые файлы:

- [Скачать base](https://huggingface.co/ggerganov/whisper.cpp/resolve/5359861c739e955e79d9a303bcbc70fb988958b1/ggml-base.bin).
- [Скачать medium-q5_0](https://huggingface.co/ggerganov/whisper.cpp/resolve/c521a4b02f422512d734391fdf08bb08c0862f68/ggml-medium-q5_0.bin).
- [Скачать large-v3](https://huggingface.co/ggerganov/whisper.cpp/resolve/c521a4b02f422512d734391fdf08bb08c0862f68/ggml-large-v3.bin).

Сохраните модель, например, в `C:\OBS-Models\`. ZIP распаковывать для неё не нужно: эти ссылки дают готовый `.bin`. Можно просто перенести уже проверенную модель со старого ПК.

Ожидаемые SHA256:

```text
ggml-base.bin
60ed5bc3dd14eea856493d334349b405782ddcaf0028d4b5df4088345fba2efe

ggml-medium-q5_0.bin
19fea4b380c3a618ec4723c3eef2eb785ffba0d0538cf43f8f235e7b3b34220f

ggml-large-v3.bin
64d182b440b98d5203c4f9bd541544d84c605196c4f7b845dfa11fb23594d1e2
```

Пример проверки medium в PowerShell:

```powershell
$ErrorActionPreference = 'Stop'
$modelPath = 'C:\OBS-Models\ggml-medium-q5_0.bin'
if ((Get-Item -LiteralPath $modelPath).Length -ne 539212467) {
    throw 'Неверный размер модели: загрузка не завершена или выбран другой файл.'
}
$expected = '19fea4b380c3a618ec4723c3eef2eb785ffba0d0538cf43f8f235e7b3b34220f'
if ((Get-FileHash -LiteralPath $modelPath -Algorithm SHA256).Hash -ne $expected) {
    throw 'SHA256 модели не совпадает.'
}
Write-Host 'Модель medium-q5_0 проверена.'
```

Плагин сам проверяет размер и SHA256. Другой одноимённый файл будет отклонён. Не подходят `.en`, GGUF, ONNX, PyTorch, Turbo и другие варианты квантования, отсутствующие в таблице. Переименование неподходящего файла не сделает его совместимым.

## 5. Подготовка аудио в OBS

1. В OBS выберите **Настройки → Аудио** и проверьте нужный микрофон. Либо добавьте отдельный источник **«Захват входного аудиопотока»** и выберите устройство.
2. Произнесите фразу и убедитесь, что индикатор выбранного источника движется. Уровень не должен постоянно упираться в красную зону.
3. На этом же аудиоисточнике откройте **Фильтры → Аудиофильтры → + → Live Translate — локальный Whisper (RU / EN)**.
4. Не добавляйте один и тот же фильтр на несколько копий одного микрофона: иначе появятся дубли распознавания и лишняя нагрузка.

Плагин получает звук именно из источника с этим фильтром. Чтобы распознавать другой звуковой источник, ставьте фильтр на него. Входной язык текущей версии фиксирован как **русский**; это не настройка автоматического распознавания любого языка.

## 6. Создание браузерных субтитров

1. В нужной сцене нажмите **Источники → + → Браузер**. Назовите его, например, `Субтитры Live Translate`.
2. Для сцены **1920×1080** задайте **ширину 1920, высоту 384**.
3. Галочку **«Локальный файл» выключите**. Не выбирайте `index.html` вручную. Начальный URL будет заменён плагином при подключении.
4. Разместите источник поверх видео, например внизу кадра. Проверьте порядок источников: субтитры должны находиться выше непрозрачных источников изображения.
5. В аудиофильтре Whisper выберите этот Браузер в поле **«Выходной источник (Text GDI+ или Браузер)»**. Если его ещё нет в списке, нажмите **«Обновить статус и список источников»**.
6. Нажмите **«Подключить выбранный Браузер»**. Плагин установит URL вида `http://127.0.0.1:.../.../index.html` и параметры обновления. Обычно вручную менять FPS и поведение загрузки страницы не требуется.

`127.0.0.1` означает этот же компьютер. Не переносите URL со старого ПК и не открывайте порты на роутере: порт и адрес сессии создаются автоматически. Источник должен быть виден в нужной сцене. Скрытый источник не расходует время чтения субтитров.

Другие размеры допустимы: ширина определяет перенос строк, высота влияет на размер текста. **2304×384 не является обязательным размером.** Для другого разрешения подберите ширину под свою сцену и проверьте область в предпросмотре OBS.

## 7. Настройка фильтра и запуск модели

В свойствах аудиофильтра:

| Параметр | Как настроить |
|---|---|
| Локальная модель Whisper | Укажите полный путь к выбранному `.bin` на этом ПК |
| Выходной источник | Созданный Браузер с субтитрами |
| Переводить русскую речь на английский | Включено — английский перевод; выключено — русская расшифровка |
| Использовать GPU (Vulkan) | Включите при подходящем GPU; при ошибке попробуйте CPU |
| Потоки CPU | По умолчанию 2; допустимо 1–32. В CPU-режиме подбирайте по нагрузке, оставляя ресурсы OBS |
| Стиль субтитров | Выберите нужный из раздела 8 |

После выбора корректной модели и включения фильтра запускается загрузка. В GPU-режиме затем выполняется прогрев; до его завершения речь не принимается. На новом ПК или драйвере это может занять дольше обычного — дождитесь статуса прослушивания и только затем начинайте проверку.

**Не нужно запускать модель второй командой или отдельной программой.** При следующем запуске OBS включённый фильтр снова загрузит выбранную модель. Если вы переместили `.bin`, исправьте путь в фильтре. Смена модели или вычислительного режима может потребовать ожидания завершения текущей обработки.

### Особенности GPU на другом ПК

Проверенный стенд — **NVIDIA RTX 4070 SUPER, 12 ГБ VRAM**. Это пример проверенной конфигурации, а не обязательная модель видеокарты и не гарантированный минимум памяти.

Текущая версия выбирает Vulkan-устройство с предпочтением NVIDIA и допускает только выбранное устройство с индексом **0 в списке Vulkan плагина**. Это ограничение используемой версии Whisper. Номер «GPU 0» в Диспетчере задач Windows может отличаться. На ноутбуке с несколькими GPU или другой конфигурации возможен статус «GPU недоступен», даже если видеокарта исправна. Тогда отключите GPU и проверьте base на CPU; не требуется отключать встроенную графику или менять системные DLL.

AMD/Intel и прочие устройства требуют отдельной проверки на конкретном ПК; успешный запуск на проверенной NVIDIA не гарантирует их совместимость. Если VRAM не хватает при одновременном запуске игры/OBS, выберите меньшую модель или CPU.

## 8. Стиль текста и подложка

Все эти настройки находятся **в аудиофильтре Whisper**, а не в поле пользовательского CSS Браузера.

Стилями можно переключать обычный текст, Матрицу, Консоль, Киберпанк, Матрицу с падающим кодом, фэнтези и Катай. Подложка выбирается отдельно: по стилю, прозрачная, сплошная, градиент, пергамент, орнамент Катая или собственное изображение.

Для своих параметров включите **«Использовать ручные настройки подложки»**. Доступны цвета, непрозрачность, горизонтальные/вертикальные отступы, скругление и рамка. Для изображения поддерживаются PNG/JPEG/WebP до **16 МиБ**, заполнение с обрезкой и вписывание целиком. Путь изображения на новом ПК нужно указать заново. Кнопка сброса возвращает подложку к оформлению стиля.

Кнопка **«Показать пример стиля»** помогает проверить вывод; пример не перебивает настоящую очередь речи. Смена оформления сохраняет очередь и не перезапускает модель.

На экране до трёх строк. Новые появляются снизу, предыдущие уходят вверх, когда их можно было дочитать. Минимум три секунды полностью читаемого текста отсчитываются после эффекта появления; длинные строки получают больше времени. При быстрой речи отставание субтитров может увеличиваться — это ожидаемая плата за приоритет чтения. После паузы дождитесь завершения очереди.

После обновления файлов оформления откройте свойства Браузера и нажмите **«Обновить кэш текущей страницы»**. Перезагрузка может повторить ещё не дочитанную фразу. Ручная замена URL останавливает управление источником: для возврата нажмите подключение в фильтре.

### Альтернатива: Text (GDI+)

Можно создать Text (GDI+) вместо Браузера и выбрать его в том же фильтре. Шрифт и область настраиваются в свойствах Text (GDI+); прежние три эффекта поддерживаются. Новые браузерные эффекты, орнаменты и настройки подложки требуют Браузера. Для GDI+ не включайте чтение текста из файла.

## 9. Проверка первого запуска

1. Включите фильтр и дождитесь прослушивания. Нажмите обновление статуса или заново откройте свойства фильтра, если надпись ещё не обновилась.
2. Покажите Браузер в текущей сцене и проверьте пример стиля.
3. Скажите по-русски: «Проверка субтитров. Сегодня я настраиваю трансляцию на новом компьютере». Сделайте паузу около секунды.
4. Проверьте язык результата: русский при выключенном переводе, английский при включённом.
5. Произнесите несколько предложений. Проверьте перенос строк, движение снизу вверх и время на чтение. После паузы очередь должна завершиться и скрыться.
6. Сделайте короткую тестовую запись OBS и просмотрите её: текст должен попадать в кадр, а звук — оставаться нормальным.

Точная задержка зависит от CPU/GPU, модели, драйвера и нагрузки игры. На слабом ПК сначала проверьте base. В режиме RU→EN черновой английский текст может уточняться во время речи; это нормальная работа распознавания.

## 10. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Фильтра нет в списке | OBS x64, Visual C++ x64, путь и вложенность папок, отсутствие второй DLL; после установки перезапустите OBS |
| Не удаётся загрузить DLL | Журнал OBS, совместимость версии OBS/CPU, Redistributable и наличие системной `vulkan-1.dll`; если Vulkan Runtime отсутствует, нужна установка совместимого драйвера или отдельная CPU-сборка |
| «Файл модели отсутствует» | Путь именно на новом ПК, существование файла и доступ к нему |
| «Нужна проверенная модель» | Точный размер/SHA256, не HTML-страница вместо загрузки и не другой формат/квантование |
| «GPU недоступен» / ошибка GPU | Драйвер с Vulkan, ограничение Vulkan0, свободная VRAM; для проверки выключите GPU и используйте base |
| Микрофон слышен, текста нет | Фильтр на правильном источнике, прогрев завершён, уровень достаточно высокий; тихая речь ниже порога около −40 dBFS может не обрабатываться |
| Пример виден, речь не распознаётся | Проверьте входной источник, язык речи, модель, статус фильтра и его включение |
| Пустой Браузер, примера нет | Правильный источник выбран и подключён; «Локальный файл» выключен; установлен весь `data/overlay`; Браузер виден и находится поверх видео |
| После обновления старая анимация | Обновите кэш страницы в свойствах Браузера |
| Текст выходит за кадр | Размер Браузера, масштаб/обрезка/позиция источника, базовое разрешение сцены; для 1080p начните с 1920×384 |
| Стиль изменился, подложка — нет | Проверьте явный выбор подложки и ручные настройки; для автоматического оформления выберите «По стилю» или сброс |
| Задержка растёт | Различайте очередь чтения и медленное распознавание; сделайте паузу. Для обработки уменьшите модель/нагрузку либо используйте GPU |
| Переполнение аудио или субтитров | Очереди ограничены. Дождитесь доступного вывода, снизьте нагрузку и выключите/включите фильтр; перезапуск сбрасывает текущую сессию |
| Источник переименован или заменён | Обновите список, выберите его заново; для Браузера нажмите подключение |

Журнал: **Справка → Файлы журналов → Просмотреть текущий журнал**. Ищите `obs-live-translate`, `ModelInvalid`, `GpuUnavailable`, `GpuInitFailed`, `RequestedGpu`, `using Vulkan`, `BrowserStartFailed`, `CaptionBacklogFull`. Ошибки и состояние прогрева помогают отличить проблему модели от проблемы отображения.

Если источник «Браузер» отсутствует вообще, проверьте полноценную установку OBS с компонентом obs-browser. Антивирус/брандмауэр не нужно отключать; если защитное ПО блокирует локальный мост, сначала изучите его журнал и разрешайте только конкретную доверенную установку по правилам своей системы.

## 11. Повседневный запуск и перенос

После первоначальной настройки достаточно запустить OBS, дождаться загрузки/прогрева включённого фильтра и открыть сцену с видимыми субтитрами. Файл модели должен оставаться на выбранном месте. Постоянное подключение к интернету не требуется; модель и обработка речи локальные.

Для следующего ПК повторите установку пакета, перенос/проверку модели, выбор микрофона и подключение нового Браузера. Путь модели, устройство микрофона, изображение подложки и URL сессии не являются переносимыми настройками «как есть».

## 12. Обновление и возврат к стабильной версии

Сохраняйте стабильный ZIP, манифест и модель. Перед заменой DLL закрывайте OBS и делайте резервную копию установленного плагина. Для возврата скопируйте папку из стабильного ZIP на её место, проверьте манифест и запустите OBS. Коллекцию сцен восстанавливайте отдельно только при необходимости.

Не заменяйте стабильные архивы при экспериментах. Эта инструкция является отдельным дополнением к стабильной версии и не меняет её код, настройки или контрольные суммы.
